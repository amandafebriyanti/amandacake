
# Amandacake 🧁 - E-Commerce Web Application

Amandacake adalah aplikasi web *e-commerce* berbasis **Python Flask** yang dirancang untuk mensimulasikan pengalaman belanja *online* yang modern, responsif, dan interaktif. Antarmuka aplikasi ini terinspirasi dari *marketplace* populer dengan alur transaksi operasional yang lengkap dari hulu ke hilir.

## ✨ Fitur Utama

- **Katalog Produk Dinamis & Pencarian:** Menampilkan 24 varian produk dengan filter kategori (Kue Tar, Kue Kering, Puding) dan fitur pencarian kata kunci.
- **Keranjang Belanja Pintar (Smart Cart):** Sistem keranjang yang memungkinkan pengguna menyesuaikan kuantitas (qty) khusus dan menghitung total belanja secara otomatis.
- **Manajemen Profil & Buku Alamat:** Dasbor pengguna bergaya *split-sidebar* untuk menyimpan, mengubah data diri, serta mengatur alamat pengiriman.
- **Checkout & Simulasi Pembayaran:** Mendukung instruksi dinamis untuk pembayaran melalui Transfer Bank, QRIS, maupun *Cash on Delivery* (COD).
- **Riwayat Pesanan (Order History):** Melacak dan mencetak struk digital riwayat transaksi yang pernah dilakukan oleh pelanggan secara *real-time*.
- **Otentikasi & Keamanan Akun:** Fitur simulasi *login*, pendaftaran akun baru, hingga manajemen pembaruan *password*.

## 🛠️ Teknologi yang Digunakan

- **Backend / Framework:** Python, Flask
- **Frontend:** HTML5, CSS3 murni (Custom CSS)
- **Template Engine:** Jinja2
- **Database:** Struktur data lokal (Python Dictionary)
- **Ikon & Tipografi:** FontAwesome 6, Google Fonts (Roboto)
- **IDE:** Visual Studio Code
